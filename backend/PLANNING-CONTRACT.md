# Connected planning contract

All amounts are integer pesewas. Every mutation includes `attemptId`. Money commands also include `pin`; results use `{ok:true,sandbox:true,currency:"GHS",account,...}`. Shared dispatcher authenticates and applies idempotency. All IDs UUID. Client never persists PINs or codes. Optional deadline dates use YYYY-MM-DD.

- `plan.get {}` -> `{plan:{revision,periodStart,periodEnd,allowanceDate,expectedAllowance,categories:[{id,name,amount,spent,remaining}],plannedRemaining,leftAfterPlan},boxes:[...],ious:[...]}`. Empty plan has revision 0. Expected allowance/IOU money is informational and never spendable.
- `plan.save {revision,periodStart,periodEnd,allowanceDate?,expectedAllowance?,categories:[{id?,name,amount}]}` -> `{plan}`. 1–20 categories. Dates required; period <=370 days, no period rewrite after spending. Pass current revision; all existing nonzero-spent categories retained. Source-aware payment payload may add `budgetCategoryId`; hook verifies ownership and updates actual plan spending atomically. Missing source is unplanned and does not silently consume Essentials.
- `box.list {}` -> `{boxes:[{id,name,goal,balance,accountId,targetDate,partnerHandle,protected}],partnerInvitations:[{id,ownerHandle,partnerHandle,status,expiresAt}],releaseRequests:[{id,boxId,boxName,ownerHandle,partnerHandle,amount,status,expiresAt}]}`. Lists owner boxes plus invitation/release inbox shared with signed-in partner.
- `box.partner.invite {partnerHandle}` -> `{invitation:{id,...}}`. Invites exact active other handle. `box.partner.respond {invitationId,accept,pin}` -> accepted returns `{invitation,partnerCode}` ONLY to partner. Owner enters that code to create protected box. Codes expire; never list/announce codes to owner.
- `box.create {name,goal,targetDate?,partnerInvitationId?,partnerCode?}` -> `{box}`. Accepted invitation/code required before protected box creation. Normal box omits both.
- `box.update {boxId,name?,goal?,targetDate?}` -> `{box}`. Cannot remove/change protection through update. `box.archive {boxId}` requires zero balance and no live hack.
- `box.save {boxId,amount,pin}` and `box.withdraw {boxId,amount,pin,releaseId?,partnerCode?}` -> `{box,receipt}` actual shared ledger. Protected withdraw requires amount-bound partner approval code.
- `box.release.request {boxId,amount}` -> `{release}` (expires 15 minutes). `box.release.decide {releaseId,approve,pin}` -> `{release,partnerCode?}` to partner only. Approvals do not move funds. `box.release.cancel {releaseId}` owner only.
- `hack.save {boxId,rule:"roundup"|"percent"|"fixed",value,enabled:true|false}` -> `{hack}`. Roundup `value`=pesewa increment; percent=whole percent 1–100; fixed=pesewas. `hack.delete {boxId}`. `box.list` box includes `hack` or null. After consumer transfer/merchant payment, hook posts valid hack savings from available actual funds, skipping a rule if insufficient. No automatic credit from expected funds.
- `iou.list {}` -> `{ious:[{id,creditorHandle,debtorHandle,amount,paid,remaining,dueDate,note,status,createdBy,remindedAt}]}`. `iou.create {counterpartyHandle,direction:"borrow"|"lend",amount,dueDate,note?}` -> `{iou}` pending. `iou.respond {iouId,accept}` counterparty only -> active/declined. Creator cannot accept for other person. `iou.remind {iouId}` creditor only, once per day; server notification, no external message. `iou.cancel {iouId}` creator while pending, or creditor forgive outstanding; no funds moved. `iou.pay {iouId,amount,pin}` debtor only actual shared ledger, partial/full; cannot overpay or pay unaccepted claim.
- `insight.get {}` -> `{insights:{available,protectedSavings,plannedRemaining,leftAfterPlan,owedToYou,youOwe,periodSpent,dailyBurn,runwayDays,nextAllowanceDate,expectedAllowance,lateAllowance,recentSpending:[...]}}`.
- `money.chat {question}` -> `{answer,grounded:true,engine:"ledger-calculations",insights}`. Computes real records; no pretend external AI, bank/MoMo or unseen finances.
- `recovery.plan {}` -> `{recovery:{available,plannedRemaining,leftAfterPlan,dailyEssential,runwayDays,allowanceLate,steps:[...]}}`.

Money command receipt types: `box.save -> box_save`, `box.withdraw -> box_withdraw`, `iou.pay -> iou_payment`. Receipt can be enriched with `boxId` / `iouId`; parent dispatcher adds based on persisted related record. IOU/group/box balances never added to consumer Everyday.

Additional connected parity:
- `plan.save` accepts `keepBack` pesewas (default 0). `plan.get` returns `keepBack`; plannedRemaining includes keepBack, so leftAfterPlan excludes it.
- `recovery.get {}` -> `{recovery:null|{id,userId,status,checkInDate,dailyLimit,protectedCategoryIds,adjustments,createdAt}}`. `recovery.save {checkInDate,dailyLimit,protectedCategoryIds?:[uuid],adjustments?:[{categoryId,amount}]}` -> `{recovery,plan}`. Applies reductions without erasing spent amounts. Active recovery pauses automated hacks centrally. `recovery.finish {recoveryId}` -> `{recovery}` marks complete; never fabricates allowance credit.
- `money.overview {}` -> `{overview:{everyday,savings,external,totalTracked,expectedIous,accounts:[{id,name,kind,balance,updatedAt}]}}`. External records informational; never spendable.
- `money.record {recordId?,name,kind:"cash"|"bank"|"momo",balance,note?}` -> `{record:{id,...}}` creates/updates manual balance with immutable history. `money.history {recordId}` -> `{history:[{id,balance,note,recordedAt}]}`. `money.archive {recordId}` hides external account without changing shared funds.
