# Task-prop illustration system

This pass addresses the weak connection between the page's purpose and its illustration. It uses upper-body and hands compositions with a dominant task object, rather than a distant full-body figure holding a small phone.

The original `student-expressive.png`, `friends-editorial.png` and `thoughtful-refined-4.13.png` were inspected and supplied as image references. The cast keeps the original black-ink/white-body drawing style and ochre/orange/navy/cream Kente or wax-print clothing. No green apparel, black blazer or physical ring was introduced. All original artwork remains unchanged.

| Asset | Readable task | Prop hierarchy |
| --- | --- | --- |
| `/assets/clarity-tasks/chat-conversation.png` | Asking and receiving an answer | Large upright phone and two empty overlapping speech bubbles; engaged braided female |
| `/assets/clarity-tasks/planning-calendar.png` | Planning a period | Large undated month-style calendar, one blank card and open notebook; curly-haired male places the card |
| `/assets/clarity-tasks/help-question.png` | Consulting useful information | Large open reference booklet, pencil and one question-mark bubble; attentive curly-haired male |

The Chat bubbles contain no text or symbols. The calendar has no dates, numbers, ticks or labels. Help's single question mark is the only intentional glyph. No amounts, currency, payment statuses, unsupported date claims or app controls are embedded. No headset or agent implies live human assistance. Legon scenery stays in a separate background layer.

## Production and inspection

Each asset was generated by a separate built-in image-generation call with `transparent_background: true`, then copied without pixel editing into the project. All are 1536 × 1024 RGBA PNGs, with fully transparent corner pixels and no green-dominant visible pixels in the metadata check. This is flat raster artwork, not rigged character animation.

Visual inspection confirms two hands per figure, complete heads and props, readable task objects and the original textile identity. The phone/bubbles, calendar and book dominate their compositions. At small sizes, the large object silhouettes should carry the meaning before facial detail or shirt motifs. This is an art-direction judgement; a supported rendered-device check is still needed to establish actual perceived clarity at 64 CSS pixels. The calendar grid is deliberately schematic, not a dated plan. The Help booklet's short rules stand for information, not a real article.

The final interface should keep these as decorative art beside real accessible labels. Use a larger invitation image for an empty Chat screen and collapse it once a conversation begins. Keep planning and Help art subordinate to their working controls. Root implementation owns route selection, sizing, colour accents and motion.
