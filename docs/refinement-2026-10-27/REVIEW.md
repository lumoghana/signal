# Monochrome refinement

The user authorised the review recommendations and asked whether accordions would conceal features and require continual education. This pass keeps the seven money destinations visible in Menu and folds only account/support. Closed summaries list the actual destinations; both sections can stay open independently. Their open state is remembered only in memory for the exact current account state. No new saved preference or foreign-account reader is introduced. The native sidebar's focus, inert background, history, task handoff and close controls remain.

Supporting text formerly set to 10–11px is larger across edition presentation styles. Core menu labels, descriptions and previews have separate readable sizes. The normal Home still fits 375×667 and 390×844; only end whitespace was released. Enlarged and unusually long content scrolls. Balance-eye comparisons across ten large-value/viewport pairs showed zero displacement of the main card, savings card, quick actions and eye control.

The new edition-owned collection adapter uses the existing controller's facts to show Details → People & rules → Review during setup. Existing collection and proposal pages group role, exact payment rule and next action. Invitation summaries preserve the original exact role and mandate blocks. Acceptance counts remain on pending mandate cards. Existing direct controls, consent, sample boundaries, thresholds, funds, engine guards, and contributor/approver/organiser authority are unchanged.
