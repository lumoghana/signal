Glyph verification with fontTools cmap:
Manrope contains G, H, all decimal digits, decimal/comma punctuation and U+2212 minus.
The distributed Manrope fonts do NOT contain U+20B5 Ghana cedi. This must not be represented as native Manrope coverage.
The existing bundled Lumo Sans Regular/Medium/Semibold/Bold faces DO contain U+20B5 and are the deliberate currency-only supplement.

Suggested CSS (root owns final CSS integration):

 font-weight: 200 800; font-style: normal; font-display: swap;
}
