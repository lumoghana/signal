# Expressive illustration pass

This pass adds three original Lumo scenes. They use the illustration-first cast as the identity reference: black curly hair, angular nose, dot eyes, long youthful proportions, white filled face and limbs, confident black contours and orange/navy Ghanaian textile details. The uploaded Minna screens informed the brief's emphasis on acting and clear silhouettes; none was used as a generation input or traced.

The original eight-scene textile family remains available for other journeys. The Pause scene is deliberately neutral, with no food, sneakers, laptop or money handover to contradict the calculated consequence. A pending, failed, reversed, unknown-delivery or missing transaction cannot use the new confirmed-result scene. Confirmation gating reuses the existing `L.clarityArt.confirmed` check. Artwork rendering never changes account state.

## Construction and use

- All three are separate 1536 × 1024 RGBA PNGs generated through the built-in image tool, saved without pixel edits or recolouring. Generated alpha is retained. All four image corners are fully transparent.
- One complete scene is used at a time. Financial figures, comparison labels and statuses remain real interface text.
- The same original character, shirt and palette recur with distinct gestures. Clothing carries the small colour area; interface highlights retain the existing lime.
- The module supplies `.expressive-art-home`, `.expressive-art-pause` and `.expressive-art-confirmed` hooks, alongside the existing `.clarity-art` and size classes. Home and confirmed result use everyday scale; Pause uses compact decision scale.
- These are flat image masters, **not rigged character assets**. Shared entrance motion may move the whole scene. There is no claim that hands or facial features animate independently. A future pose animation requires separately drawn and rigged layers.
- The Home generation initially had a third arm holding a phone. The built-in edit tool removed that arm and phone. Only the corrected two-arm version is included.

## Checks

`node tests/expressive-art.test.cjs` checks PNG signature, dimensions and RGBA encoding; one image per scene; intended Home/Pause scope; retained fallbacks; confirmed-delivery gating; and absence of state mutation while rendering. The existing `clarity-art.test.cjs` still checks all eight earlier original masters and their route semantics.

The three outputs were visually inspected through the image tool. Actual phone rendering, perceived scale within the task sheet and full device interaction require supported browser QA; the unit checks do not establish them.

## Generation prompts

Built-in image generation was used, with `transparent_background: true` for every call. The first call used the existing `student-expressive.png` and `thoughtful-refined-4.13.png` as identity references. Subsequent calls used the corrected Home and Pause outputs to retain the same cast.
