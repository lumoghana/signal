# Ask Lumo · Legon campus illustrations

The user asked for bold student settings with a Legon backdrop, making Ask Lumo prominent as Lumo's intelligent-banking feature.

Four original illustrations replace the small vector character scenes. Each shows Ghanaian student life and a recognisable Balme Library clock tower/arches, in monochrome with acid-lime accents. The goal scene shows a laptop and planning; runway shows class/time; spending shows a campus food/receipt conversation; affordability shows food/book choices. No reference artwork, third-party logos, in-image financial figures or UI text is imported. The unbranded goal shoes received one targeted built-in edit.

Built-in image generation was used. Exact generation prompts and cleanup prompt are stored beside this review. Final web assets are `dist/assets/ask-lumo-campus/{goal,runway,spending,affordability}.webp`, each1774×887, roughly99–114KB. Encoding changes format only. Home fetches only the scene selected by its existing factual prompt logic.

The larger Ask Lumo heading and full panel art lead one genuine Chat action. The compact horizontal Add money/Transfer/Collect controls and Money Boxes row make space without hiding financial values. The visual greeting is removed; its escaped text remains accessible. Money Story navigation, top chat access, swipes, actual answers, privacy targets and financial rules remain unchanged.
