# Full-screen Chat banking · 23 October 2026

Implemented in both independently hosted editions. Home and Chat are adjacent destinations: a deliberate left swipe from non-interactive Home content opens Chat, and a right swipe returns Home. The visible Home Chat button and existing Chats navigation remain alternatives. Mouse drags, vertical scrolling, short/cancelled gestures, multiple fingers, fields, controls and open sheets cannot trigger a page swipe. Pinch zoom remains available. Reduced motion skips the page transition.

Chat uses the app viewport with its own Home / exact Lumo wordmark / Actions header. Bottom navigation is hidden in Chat and its contextual tasks. The conversation scrolls independently; the composer remains separate from it and responds to the existing visual-viewport keyboard controller. Active conversations remove introductory decoration but retain an accessible heading. Each edition retains its own typography, colour and controls.

Actions opens one content-sized task sheet for Campus Pay, sending, adding/requesting money, editing Budget, Money Boxes and the money story. Existing controllers own every operation. Related steps replace the same surface rather than stacking dialogs. A payment still passes through the existing conditional Pause and separate authorisation. Completing a payment or deferring optional Budget setup after funding returns to the conversation. No financial calculation, security threshold, storage key or payment-success rule changes.

Unsent text, conversation history, spending context, unfinished amount clarification and reading position survive Home visits and task returns. Existing saved records remain in each edition's independent store. The Chat context cache is session-only; it adds no persistence reader.
