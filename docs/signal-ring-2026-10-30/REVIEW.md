# Signal ring Lux and dark Home

The user explicitly approved the supplied dark-card homepage and replacing the folded-L Lux with the small white-faced lime ring. This update applies that direction to the independent Signal edition at its existing public link. Monochrome is untouched.

## Result

Home has a dark Room to spend card, lime primary amount, ring Lux, fuller Add money/Pay/Collect tiles, a pale factual insight panel, paired Money Boxes/Money Story cards and a lime Home indicator. The same white inset face with two eyes appears in page-family artwork, Chat/onboarding identity, loading, installable icons and Pause. The Pause cutout retains a raised five-finger palm.

The reference's illustrative numbers, profile photo, daily-spending claim and 'on track' reassurance were not copied. The actual account's existing facts and customer identity remain authoritative. The breakdown stays labelled Planned costs rather than Set aside: this deduction is planned Operational costs, while Money Boxes are separate Savings funds. Room to spend is the same existing room calculation, not a new financial value. No expected allowance or unpaid receivable is added to available funds.

- Home markup changes only titles, supporting labels, decorative artwork and wrappers. All money IDs, private-value reserve, native handlers, budget/date links and truthful context remain.
- `signal-ring-home.css` loads last and targets both current and retained-parent views. Normal screens follow the reference; short screens omit only decorative greeting/action helper lines. Narrow/enlarged content stacks and scrolls naturally.
- Exceptionally large amounts use full-width breakdown rows so decimals remain with the balance. Ordinary breakdown facts remain side by side.
- Global Signal presentation adapters and the loading/icon references use ring artwork. Stable `.signal-pause-character` CSS replaces four filename-dependent Pause selectors; native `data-pause-ring` and `data-money-slip` hooks remain.
- No shared financial, payment, authentication, persistence, approval, mandate, IOU, recovery, savings or Pause timing source changed. No peer baseline hashes were regenerated.
- Existing tests select the primary action label separately from its new helper text. Native destination, action uniqueness, financial outcome, privacy, timing, cancellation and separate-authentication assertions are preserved.
