# Lumo branding release 2.15.0

The product, its assistant and its mascot now share one name: **Lumo**. The consumer and merchant chat entry point is **Ask Lumo**; learning uses **Learn with Lumo**. The existing mascot artwork is retained.

This change covers current consumer, merchant and admin copy, accessibility labels, learning stories and rewards, assistant prompts and service messages, plus the paired Android release. Known old application-owned assistant and reward labels are normalized for display. User questions, customer and shop names, saved financial records and learning progress retain their original values.

Internal `lux` API routes, identifiers, storage keys and asset filenames remain compatible with existing data and clients. Dated historical release records and database migrations remain authentic. No financial calculation, approval, recovery control, provider connection or database migration is changed by this naming release.
